# Attendex – Smart Attendance System Using Face Recognition

## 📌 Project Overview
Attendex is a Smart Attendance System designed to simplify attendance management using face recognition technology. The system aims to reduce manual work, save time, and make attendance tracking more convenient.

## 🎯 Objectives
- Automate the attendance process using face recognition.
- Reduce manual attendance errors.
- Help manage and track attendance records efficiently.
- Provide a user-friendly interface for attendance management.

## 🛠️ Technologies Used
- **Frontend:** React.js
- **Backend:** Python, Django
- **Database:** PostgreSQL
- **Face Recognition:** Facial encoding and face comparison

## ✨ Key Features
- Face recognition-based attendance system.
- User-friendly web interface.
- Attendance record management.
- Prevention of duplicate attendance entries.
- Database integration for storing records.

## ⚙️ How It Works
1. The user opens the Attendex application.
2. The system captures an image using a camera.
3. The face recognition process compares the captured face with registered face data.
4. If a match is found, attendance can be recorded.
5. Attendance information is stored in the database.
